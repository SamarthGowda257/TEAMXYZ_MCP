# 06 — Database (Supabase Postgres)

## Principles
- Postgres is the single source of truth for the bot, the website and the jobs.
- Integrity lives in the database: foreign keys, `CHECK`s, unique and exclusion constraints. Code checks are a second line.
- Timestamps are `timestamptz`; display in `Asia/Kolkata`.
- IDs: internal `bigint` identity keys; human-facing codes (`WN-4821`, `LR-20931`, `WL-…`, offer codes) are separate unique text columns.
- All data is fake and generated by `db/seed/generate.py`.

## Schema (write as `db/schema.sql`, idempotent with `IF NOT EXISTS`)
```sql
create extension if not exists pg_trgm;          -- fuzzy doctor/patient name search

-- Hospital ---------------------------------------------------------------
create table departments (
  id smallint generated always as identity primary key,
  code text unique not null,            -- CARD, ORTH, NEUR, ...
  name text unique not null,            -- Cardiology
  floor text, description text
);

create table doctors (
  id int generated always as identity primary key,
  code text unique not null,            -- DOC-017
  name text not null,                   -- Dr. Rajesh Iyer
  department_id smallint not null references departments(id),
  qualification text,                   -- MBBS, MD, DM (Cardiology)
  experience_years smallint,
  languages text[] not null default '{English}',
  fee_inr int not null check (fee_inr between 200 and 5000),
  room text not null,                   -- OPD-310
  consult_days smallint[] not null,     -- ISO weekdays 1=Mon..7=Sun
  start_time time not null, end_time time not null,
  slot_minutes smallint not null default 15,
  is_active boolean not null default true,
  bio text
);
create index on doctors using gin (name gin_trgm_ops);

create table procedures (               -- MRI, CT, X-ray, lab tests, health checks
  id int generated always as identity primary key,
  code text unique not null,            -- MRI-BRAIN
  name text not null,                   -- MRI Brain (plain)
  department_id smallint references departments(id),
  price_inr int not null,
  duration_minutes smallint not null,
  preauth_required boolean not null default false,
  fasting_hours smallint default 0,
  instructions text
);

create table resources (                -- machines/rooms used by procedures
  id int generated always as identity primary key,
  name text not null,                   -- MRI Scanner 1
  procedure_category text not null      -- MRI, CT, XRAY, USG, LAB
);

create table slots (                    -- pre-generated bookable units
  id bigint generated always as identity primary key,
  doctor_id int references doctors(id),
  resource_id int references resources(id),
  starts_at timestamptz not null,
  ends_at timestamptz not null,
  status text not null default 'free' check (status in ('free','booked','blocked','held')),
  check ((doctor_id is not null) <> (resource_id is not null))
);
create unique index slots_doctor_start on slots(doctor_id, starts_at) where doctor_id is not null;
create unique index slots_resource_start on slots(resource_id, starts_at) where resource_id is not null;
create index slots_free_lookup on slots(starts_at) where status = 'free';

create table insurers (
  id smallint generated always as identity primary key,
  code text unique not null,            -- STAR, HDFCERGO, ICICILOM, NIVA, CARE, ABHI, TATAAIG, BAJAJ, CGHS, ECHS
  name text not null,
  mode text not null check (mode in ('cashless','reimbursement','both')),
  tpa_name text, documents text, notes text
);

create table coverage_rules (           -- insurer x (procedure or department)
  id int generated always as identity primary key,
  insurer_id smallint not null references insurers(id),
  procedure_id int references procedures(id),
  department_id smallint references departments(id),
  coverage text not null check (coverage in ('yes','partial','no')),
  copay_percent smallint default 0,
  cap_inr int,
  preauth_required boolean not null default false,
  preauth_turnaround_hours smallint default 24,
  check ((procedure_id is not null) or (department_id is not null))
);

create table hospital_info (
  topic text primary key,               -- address, hours, parking, visiting, emergency, facilities, pharmacy
  content text not null
);

-- People -----------------------------------------------------------------
create table patients (
  id bigint generated always as identity primary key,
  patient_code text unique not null,    -- PT-100231
  auth_user_id uuid unique,             -- Supabase auth.users.id once linked
  full_name text not null,
  phone_e164 text unique not null,
  date_of_birth date not null,
  gender text check (gender in ('female','male','other','undisclosed')),
  email text,
  preferred_language text default 'English',
  preferred_time text check (preferred_time in ('morning','afternoon','evening','any')) default 'any',
  insurer_id smallint references insurers(id),
  policy_number text,
  caregiver_name text, caregiver_phone text, caregiver_email text,
  caregiver_consent boolean not null default false,
  mobility_needs text,
  is_guest boolean not null default false,
  created_at timestamptz not null default now()
);
create index on patients using gin (full_name gin_trgm_ops);
-- is_senior is computed: age(date_of_birth) >= 60 years (do not store)

create table verification_attempts (
  phone_e164 text not null, attempted_at timestamptz not null default now(), success boolean not null
);
create index on verification_attempts(phone_e164, attempted_at desc);

-- Visits -----------------------------------------------------------------
create table appointments (
  id bigint generated always as identity primary key,
  booking_code text unique not null,    -- WN-4821
  patient_id bigint not null references patients(id),
  slot_id bigint not null references slots(id),
  doctor_id int references doctors(id),
  procedure_id int references procedures(id),
  status text not null default 'booked'
    check (status in ('booked','cancelled','completed','no_show','rescheduled')),
  reason text,
  channel text not null check (channel in ('chat','voice','web','staff','waitlist')),
  idempotency_key text unique,
  created_at timestamptz not null default now(),
  cancelled_at timestamptz, cancel_reason text
);
-- the double-booking guard:
create unique index one_active_booking_per_slot on appointments(slot_id) where status = 'booked';
create index on appointments(patient_id, status);

create table assistance_requests (
  id bigint generated always as identity primary key,
  appointment_id bigint not null references appointments(id),
  type text not null check (type in ('wheelchair','escort','interpreter','transport_desk')),
  notes text, created_at timestamptz not null default now()
);

create table waitlist (
  id bigint generated always as identity primary key,
  code text unique not null,            -- WL-3392
  patient_id bigint not null references patients(id),
  department_id smallint references departments(id),
  doctor_id int references doctors(id),
  procedure_id int references procedures(id),
  date_from date not null, date_to date not null,
  time_preference text default 'any',
  urgent boolean not null default false,
  status text not null default 'waiting' check (status in ('waiting','offered','booked','expired','cancelled')),
  created_at timestamptz not null default now()
);
create index on waitlist(status, date_from, date_to);

create table waitlist_offers (
  id bigint generated always as identity primary key,
  offer_code text unique not null,      -- 10+ char base32
  waitlist_id bigint not null references waitlist(id),
  slot_id bigint not null references slots(id),
  status text not null default 'open' check (status in ('open','accepted','expired','superseded')),
  expires_at timestamptz not null,
  created_at timestamptz not null default now()
);
create unique index one_open_offer_per_slot on waitlist_offers(slot_id) where status = 'open';

-- Records ----------------------------------------------------------------
create table lab_reports (
  id bigint generated always as identity primary key,
  report_code text unique not null,     -- LR-20931
  patient_id bigint not null references patients(id),
  appointment_id bigint references appointments(id),
  test_name text not null,              -- Complete Blood Count, Lipid Profile, HbA1c, MRI Brain report...
  status text not null check (status in ('pending','ready','collected')),
  ordered_at timestamptz not null, expected_at timestamptz, ready_at timestamptz,
  summary text,                         -- plain-language, non-diagnostic
  results jsonb                         -- shown only in the logged-in portal
);
create index on lab_reports(patient_id, ordered_at desc);

create table prescriptions (
  id bigint generated always as identity primary key,
  patient_id bigint not null references patients(id),
  doctor_id int references doctors(id),
  medicine_name text not null, dosage text, start_date date, end_date date
);

create table prescription_requests (
  id bigint generated always as identity primary key,
  patient_id bigint not null references patients(id),
  medicine_name text not null, doctor_id int references doctors(id),
  status text not null default 'pending_doctor' check (status in ('pending_doctor','approved','rejected')),
  created_at timestamptz not null default now()
);

create table bills (
  id bigint generated always as identity primary key,
  bill_code text unique not null,       -- BL-55012
  patient_id bigint not null references patients(id),
  appointment_id bigint references appointments(id),
  amount_inr int not null, insurer_paid_inr int default 0,
  status text not null check (status in ('due','paid','partially_paid','waived')),
  due_date date, created_at timestamptz not null default now()
);

-- Support & memory -------------------------------------------------------
create table handoffs (
  id bigint generated always as identity primary key,
  handoff_code text unique not null,
  patient_id bigint references patients(id),
  phone_e164 text,
  priority text not null check (priority in ('urgent','normal')),
  reason_code text, summary text not null,
  status text not null default 'open' check (status in ('open','assigned','closed')),
  created_at timestamptz not null default now()
);
create table callbacks (
  id bigint generated always as identity primary key,
  phone_e164 text not null, preferred_time text, reason text,
  status text not null default 'queued', created_at timestamptz not null default now()
);
create table checkins (
  id bigint generated always as identity primary key,
  patient_id bigint not null references patients(id), appointment_id bigint references appointments(id),
  pain_score smallint, fever boolean, symptoms_worse boolean, notes text,
  alert_raised boolean not null default false, created_at timestamptz not null default now()
);
create table nurse_alerts (
  id bigint generated always as identity primary key,
  patient_id bigint references patients(id), reason text not null,
  status text not null default 'open', created_at timestamptz not null default now()
);
create table feedback (
  id bigint generated always as identity primary key,
  patient_id bigint references patients(id), appointment_id bigint references appointments(id),
  rating smallint check (rating between 1 and 5), comment text, created_at timestamptz not null default now()
);

create table interaction_notes (        -- conversation memory
  id bigint generated always as identity primary key,
  patient_id bigint references patients(id),
  phone_e164 text not null,
  channel text,                         -- chat / voice
  summary text not null check (char_length(summary) <= 500),
  topics text[],
  outcome text,
  created_at timestamptz not null default now(),
  search tsvector generated always as (to_tsvector('english', coalesce(summary,'') || ' ' || coalesce(array_to_string(topics,' '),''))) stored
  -- , embedding vector(384)            -- only if embeddings are enabled; dimension = provider's
);
create index on interaction_notes using gin(search);
create index on interaction_notes(patient_id, created_at desc);

create table resolutions (              -- audit log of every agent/website action
  id bigint generated always as identity primary key,
  patient_id bigint references patients(id),
  actor text not null,                  -- agent:Booking / web / job:reminders
  action text not null,                 -- book_appointment, cancel_appointment, ...
  ref text,                             -- booking code etc.
  ok boolean not null,
  detail jsonb,
  created_at timestamptz not null default now()
);
create index on resolutions(patient_id, created_at desc);

create table notifications (            -- outbox
  id bigint generated always as identity primary key,
  patient_id bigint references patients(id),
  channel text not null check (channel in ('email','sms','whatsapp','voice_call')),
  template text not null,               -- booking_confirmed, reminder_24h, waitlist_offer, lab_ready, birthday...
  to_address text not null,
  payload jsonb not null,
  status text not null default 'queued' check (status in ('queued','sent','failed','simulated')),
  dedupe_key text unique,               -- e.g. reminder_24h:WN-4821
  attempts smallint not null default 0,
  created_at timestamptz not null default now(), sent_at timestamptz
);
create index on notifications(status, created_at);
```

### Reset

## Key queries (write and index for these)
- Free slots: `status='free' and starts_at between $from and $to and doctor_id = any($ids)` order by `starts_at` limit N.
- Book (transaction): `update slots set status='booked' where id=$1 and status='free' returning id` → if no row, `slot_taken`; insert appointment (unique partial index is the final guard).
- Free a slot + offer (transaction): cancel the appointment → select best waitlist match `for update skip locked` → if found, set slot `held` and insert an offer (30 min) + outbox rows; if none, set slot `free`. On expiry the jobs runner offers it to the next match or frees it. Accepting an offer moves the slot `held → booked`.
- Patient snapshot: one round trip using CTEs (patient + upcoming 3 + pending report count + last 3 notes).
- Use `explain analyze` on these with the seed volume; each should be < 10 ms.
